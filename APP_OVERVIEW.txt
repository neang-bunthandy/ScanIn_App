================================================================================
           ប្រព័ន្ធគ្រប់គ្រងវត្តមានសិស្សឆ្លាតវៃ (ScanIn Attendance System)
                    ទិដ្ឋភាពទូទៅ គោលបំណង និងមុខងារលម្អិត
================================================================================

I. គោលបំណងរួមនៃកម្មវិធី (Overall Purpose & Objectives)
--------------------------------------------------------------------------------
កម្មវិធី ScanIn ត្រូវបានបង្កើតឡើងក្នុងគោលបំណងផ្លាស់ប្តូរ និងធ្វើទំនើបកម្មប្រព័ន្ធ
កត់ត្រាវត្តមានសិស្ស/និស្សិត ពីការប្រើប្រាស់ក្រដាស ឬវិធីសាស្ត្របុរាណ មកជាប្រព័ន្ធ
ឌីជីថលស្វ័យប្រវត្តិតាមរយៈ Dynamic QR Code ដែលមានភាពរហ័ស សុក្រឹតភាព និងសុវត្ថិភាពខ្ពស់។

* បញ្ហាប្រឈមនៃវិធីសាស្ត្រចាស់ (Traditional Problems):
  - ចំណាយពេលយូរក្នុងការហៅឈ្មោះសិស្សម្តងមួយៗក្នុងថ្នាក់រៀន (ខាតពេលបង្រៀន ១៥-២០ នាទី)។
  - ងាយស្រួលក្នុងការចុះឈ្មោះជំនួសគ្នា (Proxy Attendance) ឬបន្លំវត្តមាន។
  - ក្រដាសស្រង់វត្តមានងាយនឹងបាត់បង់ ខូចខាត ឬពិបាកក្នុងការរក្សាទុករយៈពេលវែង។
  - ពិបាក និងស៊ីពេលច្រើនក្នុងការបូកសរុបស្ថិតិ និងធ្វើរបាយការណ៍ប្រចាំខែ/ឆមាស។
  - បង្កើតបន្ទុកបន្ថែមដល់គ្រូបង្រៀនក្នុងការបង្កើត ឬរៀបចំកូដមុខវិជ្ជា និងបន្ទប់ដោយខ្លួនឯង។

* ដំណោះស្រាយ និងអត្ថប្រយោជន៍របស់ ScanIn:
  - ភាពរហ័ស (Speed): សិស្សចំណាយពេលត្រឹមតែ ១-២ វិនាទីប៉ុណ្ណោះក្នុងការស្កេនកត់វត្តមាន។
  - សុក្រឹតភាព និងសុវត្ថិភាព (High Security): ប្រើប្រាស់ប្រព័ន្ធ Dynamic QR Code
    ដែលមាន Token ជាក់លាក់ និងកំណត់សុពលភាព (Countdown ៤ នាទី) ការពារការលួចថតផ្ញើបន្តគ្នា។
  - ស្វ័យប្រវត្តិកម្មទិន្នន័យ (Real-time Sync): ទិន្នន័យស្កេនត្រូវបានបញ្ជូនផ្ទាល់ទៅកាន់
    Database (MySQL) ភ្លាមៗ ជួយឱ្យគ្រូ និងរដ្ឋបាលអាចតាមដានបានគ្រប់ពេលវេលា។
  - ការគ្រប់គ្រងគណនីស្ថាប័នកណ្តាល (Centralized Institutional Account Provisioning):
    * ខាងសាលា (Admin) ជាអ្នកបង្កើត និងផ្តល់គណនី (Email & Password) ជូនទាំងគ្រូ និងសិស្ស។
      មិនអនុញ្ញាតឱ្យចុះឈ្មោះក្រៅប្រព័ន្ធដោយសេរីឡើយ ដើម្បីធានាសុក្រឹតភាព និងសុវត្ថិភាពទិន្នន័យ។
    * អ្នកគ្រប់គ្រងសាលា (Admin)៖ កាន់កាប់ផ្ទាំង Admin Panel ផ្តាច់មុខ ជាអ្នកបង្កើតគណនីគ្រូ 
      បង្កើតគណនីសិស្ស បង្កើតថ្នាក់រៀន និងចាត់តាំងគ្រូ។
    * គ្រូបង្រៀន (Lecturers)៖ ទទួលបានគណនីពី Admin (មិនមែនជាអ្នកគ្រប់គ្រងទេ)។ គ្រូប្រើប្រាស់ Laptop 
      ក្នុងថ្នាក់រៀន គ្រាន់តែដើម្បីបញ្ចាំង QR Code លើ Projector និងកែប្រែវត្តមានជាក់ស្តែងក្នុងថ្នាក់។
    * សិស្ស (Students)៖ ទទួលបានគណនីពីសាលា រួចប្រើប្រាស់ទូរស័ព្ទដៃ (Mobile App) ដើម្បីស្កេនកត់វត្តមាន។


II. មុខងារសម្រាប់សិស្ស / និស្សិត (Student Features - Mobile App)
--------------------------------------------------------------------------------
១. ការចូលប្រើប្រាស់ និងសុវត្ថិភាព (Authentication & Security):
   - សិស្សទទួលបាន Email និង Password ដំបូងពីខាងសាលា/រដ្ឋបាល ដើម្បីចូលប្រើកម្មវិធី។
   - ចូលប្រើប្រាស់ដោយសុវត្ថិភាពតាមរយៈ Laravel Sanctum Bearer Token។
   - មុខងារផ្លាស់ប្តូរពាក្យសម្ងាត់ផ្ទាល់ខ្លួន (Change Password)៖ សិស្សអាចប្តូរពីពាក្យសម្ងាត់ដំបូង
     របស់សាលា មកជាពាក្យសម្ងាត់ផ្ទាល់ខ្លួនបានគ្រប់ពេលវេលា ដោយភ្ជាប់ផ្ទាល់ទៅ Database។
   - មើលព័ត៌មានផ្ទាល់ខ្លួន (ឈ្មោះ, អត្តលេខសិស្ស STU, ដេប៉ាតឺម៉ង់, លេខទូរស័ព្ទ)។
   - គាំទ្រការប្តូរភាសា (ខ្មែរ / English) និងប្តូរផ្ទាំងពណ៌ (Light Mode / Dark Mode)។

២. ទំព័រដើម និងស្ថិតិវត្តមាន (Dashboard Overview):
   - បង្ហាញស្ថិតិវត្តមានជាក់ស្តែងគណនាចេញពី Database រួមមាន៖
     * ចំនួនវត្តមានមកទាន់ពេល (Present)
     * ចំនួនវត្តមានមកយឺត (Late)
     * ចំនួនអវត្តមាន (Absent)
   - មើលកាលវិភាគថ្នាក់រៀន និងមុខវិជ្ជាដែលត្រូវរៀនប្រចាំថ្ងៃ។
   - Pull-to-Refresh: ទាញចុះក្រោមដើម្បី refresh ទាញយកទិន្នន័យថ្មីចុងក្រោយ។

៣. ការស្កេនកត់វត្តមាន (QR Code Attendance Scanning):
   - បើក Camera ក្នុងកម្មវិធីទូរស័ព្ទដើម្បីស្កេន Dynamic QR Code ដែលគ្រូបញ្ចាំងលើ Projector។
   - គាំទ្រការវាយបញ្ចូលលេខកូដ QR Token ដោយផ្ទាល់ដៃ (ករណីកាមេរ៉ាទូរស័ព្ទមានបញ្ហា)។
   - បង្ហាញផ្ទាំងជូនដំណឹងភ្លាមៗនៅពេលកត់ត្រាបានជោគជ័យ ឬបញ្ជាក់ពីមូលហេតុបើបរាជ័យ។

៤. ពិនិត្យប្រវត្តិវត្តមានផ្ទាល់ខ្លួន (Attendance History):
   - មើលកំណត់ត្រាវត្តមានកន្លងមកទាំងអស់តាមកាលបរិច្ឆេទ មុខវិជ្ជា និងម៉ោងស្កេន។
   - ពិនិត្យមើលស្ថានភាពនីមួយៗ (មកទាន់ពេល, មកយឺត, ឬអវត្តមាន) ព្រមទាំងសម្គាល់ (Note)។


III. មុខងារសម្រាប់គ្រូបង្រៀន (Lecturer Classroom Features - Laptop & Mobile)
--------------------------------------------------------------------------------
គ្រូបង្រៀនមិនមែនជាអ្នកគ្រប់គ្រងប្រព័ន្ធឡើយ (គ្រូទទួលបានគណនី Email/Password ពី Admin)។ 
គ្រូប្រើ Laptop ក្នុងថ្នាក់រៀនភ្ជាប់ HDMI ទៅកាន់ Projector ដើម្បីសម្រួលដល់ការបង្រៀន៖

១. ពិនិត្យថ្នាក់រៀនដែល Admin បានចាត់តាំង (Assigned Classes View):
   - គ្រូឃើញតែមុខវិជ្ជា/ថ្នាក់រៀនណាដែល Admin បានចាត់តាំងឱ្យខ្លួនបង្រៀនប៉ុណ្ណោះ។
   - គ្រូគ្មានសិទ្ធិបង្កើត លុប ឬកែប្រែកូដមុខវិជ្ជាមេរបស់សាលាឡើយ (កិច្ចការនេះជាសិទ្ធិរបស់ Admin)។
   - ពិនិត្យព័ត៌មានលម្អិតនៃមុខវិជ្ជា៖ កូដ, ឈ្មោះ, បន្ទប់រៀន, ម៉ោង, ឆមាស, និងឆ្នាំសិក្សា។

២. ការបញ្ចាំង Dynamic QR Code លើ Projector ក្នុងថ្នាក់ (Projector Fullscreen Mode):
   - ប៊ូតុង "បញ្ចាំង QR (Project QR)" បើកផ្ទាំង Projector ទំហំធំ កម្រិត Contrast ខ្ពស់។
   - បង្ហាញ Countdown Timer (៤ នាទី) និងមុខងារប្តូរ Token ថ្មីស្វ័យប្រវត្តិ (Regenerate QR)។
   - ប៊ូតុងផ្អាកដំណើរការ (Pause) និងបើកដំណើរការឡើងវិញ (Resume) គ្រប់គ្រងបានរហ័ស។

៣. តាមដានវត្តមានផ្ទាល់ក្នុងថ្នាក់ (Real-time Live Attendance Monitoring):
   - មើលបញ្ជីឈ្មោះសិស្សដែលកំពុងស្កេនចូលរៀនជាក់ស្តែងភ្លាមៗ (Real-time Update)។
   - ដឹងច្បាស់ពីពេលវេលាស្កេនជាក់ស្តែងរបស់សិស្សម្នាក់ៗ។

៤. កែប្រែស្ថានភាពវត្តមានជាក់ស្តែងដោយផ្ទាល់ដៃ (Manual Attendance Update & Notes):
   - គ្រូអាចចុចប៊ូតុង "កែប្រែ" លើសិស្សម្នាក់ៗដើម្បីប្តូរស្ថានភាព៖ វត្តមាន, មកយឺត, ឬ អវត្តមាន។
   - បញ្ចូលមូលហេតុ ឬ Note ដូចជា៖ សិស្សមានច្បាប់ឈឺ, ធុរៈគ្រួសារ, ឬទូរស័ព្ទអស់ថ្ម។
   - ទិន្នន័យកែប្រែត្រូវបាន Save ចូល MySQL Database ភ្លាមៗ។


IV. មុខងារសម្រាប់ផ្នែកគ្រប់គ្រង / រដ្ឋបាល (Admin Panel Features - Web Dashboard)
--------------------------------------------------------------------------------
ផ្ទាំងគ្រប់គ្រង Admin Panel គឺសម្រាប់តែអ្នកគ្រប់គ្រងសាលា/រដ្ឋបាល (Admin) តែប៉ុណ្ណោះ 
**គ្រូ និងសិស្ស មិនអាចចូលជា Admin បានដាច់ខាត (Strict Access Control)**៖

១. បង្កើត និងគ្រប់គ្រងគណនីគ្រូបង្រៀន (Lecturer Account Management by Admin):
   - Admin ជាអ្នកបង្កើត កែប្រែ និងលុបគណនីគ្រូបង្រៀនម្នាក់ៗ ដោយកំណត់៖ ឈ្មោះ, អ៊ីមែល, ពាក្យសម្ងាត់ដំបូង
     (Initial Password), ដេប៉ាតឺម៉ង់, លេខសម្គាល់គ្រូ (Staff ID), និងលេខទូរស័ព្ទ។
   - គ្រូទទួលបាន Email និង Password ពីរដ្ឋបាលសាលាដើម្បីចូលប្រើប្រាស់។
   - ពិនិត្យបញ្ជីគ្រូបង្រៀនទាំងអស់ និងចំនួនថ្នាក់ដែលគ្រូនីមួយៗកំពុងទទួលបន្ទុកបង្រៀន។

២. បង្កើត និងគ្រប់គ្រងគណនីសិស្ស/និស្សិត (Student Account Management by Admin):
   - Admin ជាអ្នកបង្កើត កែប្រែ និងលុបគណនីសិស្សម្នាក់ៗ ដោយកំណត់៖ ឈ្មោះសិស្ស, អត្តលេខសិស្ស (Student ID: ឧ. STU001), 
     ភេទ (Gender: ប្រុស/ស្រី), ថ្ងៃខែឆ្នាំកំណើត (DOB: YYYY-MM-DD), អ៊ីមែល (Email), ពាក្យសម្ងាត់ដំបូង (Initial Password: ឧ. password123), 
     ដេប៉ាតឺម៉ង់, និងលេខទូរស័ព្ទ។
   - **មុខងារនាំចូលទិន្នន័យសិស្សជាក្រុមពី Excel / CSV (Bulk Student Import from Excel/CSV):**
     * Admin អាច Copy & Paste ឬ Import តារាងពី Excel ចូលក្នុងប្រព័ន្ធបានរាប់រយនាក់ក្នុងពេលតែមួយ។
     * គាំទ្រព័ត៌មានលម្អិត៖ ឈ្មោះសិស្ស (Name), អត្តលេខ (Student ID), ភេទ (Gender: ប្រុស/ស្រី/Male/Female), 
       ថ្ងៃខែឆ្នាំកំណើត (Date of Birth), ដេប៉ាតឺម៉ង់, និងលេខទូរស័ព្ទ។
     * ប្រព័ន្ធបង្កើត Email ស្វ័យប្រវត្តតាមអត្តលេខ (ឧ. `{code}@student.scanin.app`) និងពាក្យសម្ងាត់ដំបូង `password123` ប្រសិនបើពុំមានបញ្ជាក់។
     * ត្រួតពិនិត្យទិន្នន័យស្វ័យប្រវត្តិ ព្រមទាំងរំលងសិស្សដែលមានលេខកូដស្ទួនរួចជាស្រេចក្នុង DB។
   - សាលាប្រគល់ Email និង Password ជូនសិស្សដើម្បីយកទៅ Log In លើ Mobile App។
   - ពិនិត្យ និងគ្រប់គ្រងបញ្ជីសិស្សទូទាំងសាកលវិទ្យាល័យ។

៣. បង្កើត កែប្រែ និងចាត់តាំងគ្រូបង្រៀនលើថ្នាក់រៀន (Centralized Class Creation, Edit, Delete & Assignment):

     * បន្ទប់រៀន (Room: ឧ. Room A-301)

   - ទប់ស្កាត់ការបង្កើតកូដមុខវិជ្ជាជាន់គ្នា ឬការកក់បន្ទប់រៀនជាន់ម៉ោងគ្នា។

   - ជ្រើសរើសថ្នាក់រៀនតាម Dropdown ដើម្បីទាញយកបញ្ជីវត្តមានលម្អិត។

   - **ញែកដាច់ពីគ្នា ១០០%៖** 
     * ផ្ទាំងចូលគ្រប់គ្រង Admin (Admin Portal)៖ អនុញ្ញាតសម្រាប់តែគណនី `admin` ប៉ុណ្ណោះ។
     * បើគណនីគ្រូបង្រៀន (`lecturer`) ព្យាយាមចូលជា Admin ប្រព័ន្ធនឹងបដិសេធភ្លាមៗ ដោយជូនដំណឹងថា៖
       *"គណនីនេះជាគណនីគ្រូបង្រៀន! គ្រូមិនអាចចូលជាអ្នកគ្រប់គ្រង (Admin) បានឡើយ។"*
   - គណនីសិស្ស (`student`) មិនអាចចូលប្រើលើ Web បានឡើយ (តម្រូវឱ្យប្រើ Mobile App ប៉ុណ្ណោះ)។
   - សុវត្ថិភាពផ្ទៀងផ្ទាត់ដោយ Laravel Sanctum Token & Multi-level Role Guard។


V. ស្ថាបត្យកម្មបច្ចេកវិទ្យា (System Architecture & Tech Stack)
--------------------------------------------------------------------------------
1. Mobile App (សិស្ស និងគ្រូចល័ត)៖
   - បច្ចេកវិទ្យា៖ Flutter (Dart) — `scan_in` (Android & iOS)
   - តួនាទី៖ សិស្សប្រើគណនីដែលសាលាបានផ្តល់ឱ្យដើម្បី Log In, បើកកាមេរ៉ាស្កេន QR និងប្តូរពាក្យសម្ងាត់ផ្ទាល់ខ្លួន។

2. Web Portal (ញែកតាមតួនាទី Role Guard)៖
   - បច្ចេកវិទ្យា៖ Flutter for Web (Dart) — `scan_in_admin`
   - **Admin Portal:** សម្រាប់អ្នកគ្រប់គ្រងបង្កើតគណនីគ្រូ, បង្កើតគណនីសិស្ស, បង្កើតថ្នាក់ ចាត់តាំងគ្រូ និងមើលស្ថិតិទូទាំងសាលា។
   - **Lecturer Classroom View:** សម្រាប់គ្រូបញ្ចាំង QR លើ Projector និងកែវត្តមានជាក់ស្តែងក្នុងថ្នាក់។

3. Backend Server (ម៉ាស៊ីនបម្រើការ API)៖
   - បច្ចេកវិទ្យា៖ Laravel 12 (PHP) — RESTful API Architecture។
   - សុវត្ថិភាព៖ Laravel Sanctum (Bearer Token Authentication) & Role Guard Middleware។
   - Endpoints សំខាន់ៗ៖
     * Auth: `POST /api/login`, `POST /api/logout`, `POST /api/user/change-password`
     * Lecturers: `GET /api/lecturers`, `POST /api/lecturers`, `PUT /api/lecturers/{id}`, `DELETE /api/lecturers/{id}` (Admin Only)
     * Students: `GET /api/students`, `POST /api/students`, `PUT /api/students/{id}`, `DELETE /api/students/{id}`, `POST /api/students/import` (Admin Only)
     * Classes: `GET /api/classes`, `POST /api/classes`, `PUT /api/classes/{id}`, `DELETE /api/classes/{id}` (Admin Only), `POST /api/classes/{id}/toggle-qr`
     * Attendances: `GET /api/classes/{id}/attendances`, `POST /api/attendances/scan`, `PUT /api/attendances/{id}`

4. Database (មូលដ្ឋានទិន្នន័យ)៖
   - បច្ចេកវិទ្យា៖ MySQL (ឈ្មោះ DB: scan_in)
   - តារាងចម្បង៖ 
     * `users`: `id`, `name`, `email`, `role` (admin/lecturer/student), `code` (Staff/Student ID), `gender` (ប្រុស/ស្រី), `date_of_birth` (YYYY-MM-DD), `department`, `phone`, `password`, `created_at`, `updated_at`
     * `classes`: `id`, `name`, `code`, `room`, `lecturer_id`, `day_of_week`, `time`, `semester`, `academic_year`, `qr_token`, `qr_token_expires_at`, `qr_is_paused`, `created_at`, `updated_at`
     * `attendances`: `id`, `class_id`, `student_id`, `status` (Present/Late/Absent), `scanned_at`, `note`, `created_at`, `updated_at`
