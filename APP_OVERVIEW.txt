================================================================================
           ប្រព័ន្ធគ្រប់គ្រងវត្តមានសិស្សឆ្លាតវៃ (ScanIn Attendance System)
                    ទិដ្ឋភាពទូទៅ គោលបំណង និងមុខងារលម្អិត
================================================================================

I. គោលបំណងរួមនៃកម្មវិធី (Overall Purpose & Objectives)
--------------------------------------------------------------------------------
កម្មវិធី ScanIn ត្រូវបានបង្កើតឡើងក្នុងគោលបំណងផ្លាស់ប្តូរ និងធ្វើទំនើបកម្មប្រព័ន្ធ
កត់ត្រាវត្តមានសិស្ស/និស្សិត ពីការប្រើប្រាស់ក្រដាស មកជាប្រព័ន្ធឌីជីថលឆ្លាតវៃ
តាមរយៈ Dynamic QR Code, GPS Geofencing និង Face ID Check-In ដែលមានសុក្រឹតភាព
ល្បឿនលឿន និងសុវត្ថិភាពខ្ពស់ ភ្ជាប់ផ្ទាល់ទៅកាន់ MySQL Database (Laravel API)។

* បញ្ហាប្រឈមនៃវិធីសាស្ត្រចាស់ (Traditional Problems):
  - ចំណាយពេលយូរក្នុងការហៅឈ្មោះសិស្សម្តងមួយៗក្នុងថ្នាក់រៀន (ខាតពេលបង្រៀន ១៥-២០ នាទី)។
  - ងាយស្រួលក្នុងការចុះឈ្មោះជំនួសគ្នា (Proxy Attendance) ឬស្កេនពីក្រៅបរិវេណសាលា។
  - ក្រដាសស្រង់វត្តមានងាយនឹងបាត់បង់ ខូចខាត និងពិបាកបូកសរុបស្ថិតិប្រចាំឆមាស។

* ដំណោះស្រាយ និងសុវត្ថិភាពរបស់ ScanIn:
  - ភាពរហ័ស (Speed): សិស្សចំណាយពេលត្រឹម ១-២ វិនាទីក្នុងការស្កេន QR ឬ Face ID។
  - ការពារការស្កេនពីចម្ងាយ (GPS Geofencing & Anti-Fake GPS): គណនាចម្ងាយពិតដោយ
    រូបមន្ត Haversine និងទប់ស្កាត់កម្មវិធី Mock Location (Fake GPS) ភ្លាមៗ។
  - ការពារការស្កេនជំនួសគ្នា (Face ID + Single Device Binding): ១ គណនី = ១ ទូរស័ព្ទ
    និងប្រើប្រាស់ Face ID / Biometric របស់ទូរស័ព្ទផ្ទាល់។
  - រចនាសម្ព័ន្ធ ១ QR = ១ Session (៩០ នាទី): គាំទ្រ ៦ Sessions ស្តង់ដារក្នុង ១ ថ្ងៃ
    (07:00-08:30, 08:50-10:20, 10:30-12:00, 13:00-14:30, 14:40-16:10, 16:20-17:50)។
  - Clean Production Provisioning: គណនី Master Admin បង្កើតតាម CLI (`php artisan make:admin`)
    ចំណែក Sub-Admin, គ្រូ និងសិស្ស ត្រូវបានបង្កើត និងគ្រប់គ្រងដោយរដ្ឋបាលសាលា។
  - ចំណាំ ៖ ប្រព័ន្ធនេះមិនមែនល្អឥតខ្ចោះ ១០០% ដូចប្រព័ន្ធធនាគារទេ 
    ប៉ុន្តែវា រឹងមាំ មានប្រសិទ្ធភាពខ្ពស់ និងបិទចន្លោះប្រហោងធំៗទាំងអស់សម្រាប់សាកលវិទ្យាល័យ 
    តាមរយៈការរួមបញ្ចូលគ្នារវាង បច្ចេកវិទ្យា (QR + GPS + Face ID + Device Binding) និង ការត្រួតពិនិត្យរបស់គ្រូក្នុងថ្នាក់។


II. មុខងារសម្រាប់សិស្ស / និស្សិត (Student Features - Mobile App `scan_in`)
--------------------------------------------------------------------------------
១. ការចូលប្រើប្រាស់ និងព័ត៌មានផ្ទាល់ខ្លួន:
   - ចូលប្រើដោយ Laravel Sanctum Bearer Token និងកំណត់ Server IP (Emulator / Wi-Fi PC / Localhost)។
   - បង្ហាញរូបថត Profile លើ Home Screen (ចុចលើរូបដើម្បីចូលទៅ Profile Screen ភ្លាមៗ)។
   - Upload / ប្តូររូបថត Profile តាម Camera ឬ Gallery (`POST /api/profile/avatar`)។
   - ប្តូរពាក្យសម្ងាត់ផ្ទាល់ខ្លួន, ប្តូរភាសា (ខ្មែរ / English) និង Light / Dark Mode។

២. ទំព័រដើម កាលវិភាគ និងស្ថិតិ (Dashboard & Schedule):
   - WeekDayStrip: ជ្រើសរើសថ្ងៃតាមប្រតិទិន ដើម្បីមើលមុខវិជ្ជាត្រូវរៀនតាមកាលបរិច្ឆេទជាក់ស្តែង។
   - បង្ហាញស្ថិតិវត្តមានជាក់ស្តែងពី Database (Present, Late, Absent) និង Pull-to-Refresh។

៣. ជម្រើសកត់វត្តមាន ២ របៀប (Dual Check-In Modes):
   - របៀបទី ១ — QR Code Scan (`POST /api/attendances/scan`):
     * ស្កេន Dynamic QR Code របស់គ្រូ (ឬវាយ Token ដោយដៃ) + ផ្ទៀងផ្ទាត់ GPS & Device ID
       (មិនចាំបាច់ស្កេន Face ID ទៀតទេ ដើម្បីសន្សំសំចៃពេលវេលា)។
   - របៀបទី ២ — Face ID Check-In (`POST /api/attendances/face-checkin`):
     * ប្រើនៅពេលគ្រូបើក QR យឺត ឬសិស្សកំពុងនៅក្នុងបរិវេណសាលា (ឧ. នៅកង់ទីន)។
     * ផ្ទៀងផ្ទាត់ Face ID / Biometric (`local_auth`) + GPS Geofencing + Device ID ភ្លាមៗ។

៤. ប្រវត្តិវត្តមានផ្ទាល់ខ្លួន (Attendance History):
   - មើលកំណត់ត្រាវត្តមានទាំងអស់តាមកាលបរិច្ឆេទ មុខវិជ្ជា ម៉ោងស្កេន ស្ថានភាព និង Note។


III. មុខងារសម្រាប់គ្រូបង្រៀន (Lecturer Features - Mobile & Web)
--------------------------------------------------------------------------------
១. ទំព័រដើម និងស្ថិតិមិនរាប់ស្ទួន (Dashboard & Distinct Stats):
   - ឃើញតែមុខវិជ្ជា និងកាលវិភាគបង្រៀនដែល Admin បានចាត់តាំងឱ្យខ្លួនប៉ុណ្ណោះ។
   - រាប់ចំនួន «ថ្នាក់បង្រៀន» និង «សិស្សសរុប» តាម Distinct Course Code (មិនរាប់ស្ទួនតាមចំនួន Session)។
   - បង្ហាញរូបថត Profile លើ Home Screen (ចុចដើម្បីចូល Profile) និង Upload Profile Photo ។

២. ការបញ្ចាំង Dynamic QR Code & Projector Mode (Web & Mobile):
   - Projector Mode (Web): ប្លង់ ២ ជួរឈរ បង្ហាញ QR Code ទំហំធំ (Countdown ៤ នាទី, Regenerate,
     Pause/Resume) អមដោយផ្ទាំង **Live Check-in Feed (Auto-Refresh រៀងរាល់ ៣ វិនាទី)**។

៣. ការគ្រប់គ្រង និងកែប្រែវត្តមានសិស្ស (Manual Update & Export):
   - កែប្រែស្ថានភាពវត្តមានសិស្សដោយផ្ទាល់ (`Present`, `Late`, `Absent`, `Reset`) ជាមួយ Note
     ទាំងលើ Mobile App (`class_detail_screen`, `attendance_list_screen`) និង Web (`admin_attendances_screen`)។
   - ទាញយករបាយការណ៍វត្តមានជា **Excel (.csv UTF-8 BOM)** ឬ **Print / Save as PDF** ។


IV. មុខងារសម្រាប់ផ្នែកគ្រប់គ្រង (Admin & Sub-Admin Portal - `scan_in_admin`)
--------------------------------------------------------------------------------
១. ការបែងចែកសិទ្ធិ ៣ កម្រិតលើ Web (Strict Role Guard):
   - **Master Admin (`admin`) ៖** សិទ្ធិពេញលេញ ១០០% រួមទាំងការគ្រប់គ្រង Sub-Admin។
   - **Sub-Admin (`sub_admin`) ៖** គ្រប់គ្រងគ្រូ, សិស្ស, ថ្នាក់រៀន, វត្តមាន និងរបាយការណ៍ (គ្មានសិទ្ធិប៉ះពាល់ Master Admin)។
   - **Top-Right Profile & Interactive Crop ៖** ឈ្មោះ និង Avatar នៅជ្រុងខាងស្ដាំខាងលើ អាចចុច Upload & Crop/Zoom រូបភាព Profile ផ្ទាល់ ព្រមទាំងប៊ូតុង Change Password & Logout នៅខាងក្រោម Sidebar។

២. គ្រប់គ្រងសិស្ស/និស្សិត (`admin_students_screen.dart`):
   - គាំទ្រឈ្មោះ ២ ភាសា (ខ្មែរ + ឡាតាំង), ភេទ, ថ្ងៃខែឆ្នាំកំណើត, ដេប៉ាតឺម៉ង់, ជំនាន់, ឆ្នាំចូលរៀន, ឆ្នាំទី (១-៤) និងស្ថានភាព (`active`, `graduated`, `inactive`)។
   - **ទាញយក Template Excel (`.xlsx`) & Import File ផ្ទាល់ ៖** បុគ្គលិកសាលាអាច Download គំរូ `.xlsx`, បំពេញឈ្មោះ, ជ្រើសរើស File (`.xlsx`/`.csv`) Upload ផ្ទាល់ និងមានប្រព័ន្ធ **ពិនិត្យឈ្មោះ/កូដ/Email ស្ទួនដោយស្វ័យប្រវត្តិ**។
   - **Promote Year Level & Bulk Status ៖** ដំឡើងឆ្នាំសិក្សា (+1 ឆ្នាំ) និងប្តូរស្ថានភាពសិស្សជាក្រុម។
   - **Reset Device ID ៖** ដោះលែងការភ្ជាប់ទូរស័ព្ទពេលសិស្សប្តូរទូរស័ព្ទថ្មី។
   - **Live Search Bar & Multi-Filters ៖** ស្វែងរកតាមឈ្មោះ, កូដ, Email, ទូរស័ព្ទ។

៣. គ្រប់គ្រងគ្រូបង្រៀន & Sub-Admin (`admin_lecturers_screen.dart`, `admin_sub_admins_screen.dart`):
   - CRUD គណនីគ្រូ និង Sub-Admin ជាមួយ Live Search Bar និងតារាងពេញទទឹង។

៤. គ្រប់គ្រងថ្នាក់រៀន & Smart Subject Auto-Fill (`admin_classes_screen.dart`):
   - ពេលវាយកូដមុខវិជ្ជា (ឧ. `HMA-Y4`) ប្រព័ន្ធទាញទិន្នន័យ Default (ឈ្មោះមុខវិជ្ជា, ដេប៉ាតឺម៉ង់, ជំនាន់, គ្រូ, បន្ទប់, ម៉ោង, ឆមាស, និង +7 ថ្ងៃ) មកបំពេញដោយស្វ័យប្រវត្តិ។
   - គាំទ្រ Live Search Bar, Filter និង Grouped Class Sessions ។

៥. វត្តមាន, GPS Geofencing & របាយការណ៍ (`admin_attendances_screen.dart`, `admin_student_stats_screen.dart`):
   - **កំណត់ GPS សាលា (Campus GPS Settings) ៖** Paste `Lat, Lng` ពី Google Maps, កំណត់កាំរង្វង់ (`allowed_radius_meters`), និងបើក/បិទ `enforce_gps`។
   - បង្ហាញផ្លាកវិធីស្កេន (`QR` / `Face ID`) និងចម្ងាយ (`📍 Xm`) ក្នុងតារាងវត្តមាន។
   - **Export Excel (`.csv` UTF-8 BOM) & Print/PDF A4** គាំទ្រអក្សរខ្មែរ ១០០%។
   - **របាយការណ៍ស្ថិតិនិស្សិត ៖** សង្ខេបចំនួននិស្សិតតាមឆ្នាំចូលរៀន, ដេប៉ាតឺម៉ង់, ជំនាន់ និងស្ថានភាព។


V. ស្ថាបត្យកម្មបច្ចេកវិទ្យា (Tech Stack, Endpoints & Database)
--------------------------------------------------------------------------------
1. Frontend Mobile: Flutter (Dart) — `scan_in` (Android & iOS)
   Packages: `http`, `shared_preferences`, `image_picker`, `geolocator`, `local_auth`
2. Frontend Web Admin: Flutter for Web (Dart) — `scan_in_admin`
   Packages: `http`, `shared_preferences`, `web`, `excel`
3. Backend Server: Laravel 12 (PHP) + Sanctum Token Auth (`scan_in_backend`)
   - Auth & Profile: `POST /api/login`, `GET /api/me`, `POST /api/logout`,
     `POST /api/user/change-password`, `POST /api/profile/avatar`, `GET /api/avatars/{filename}`
   - Sub-Admins: `GET|POST /api/sub-admins`, `PUT|DELETE /api/sub-admins/{id}` (Master Admin)
   - Lecturers: `GET|POST /api/lecturers`, `PUT|DELETE /api/lecturers/{id}`
   - Students: `GET|POST /api/students`, `POST /api/students/import`, `POST /api/students/promote`,
     `POST /api/students/bulk-status`, `PUT|DELETE /api/students/{id}`,
     `POST /api/admin/students/{id}/reset-device`
   - Classes: `GET|POST /api/classes`, `PUT|DELETE /api/classes/{id}`, `GET /api/classes/{id}/students`,
     `POST /api/classes/{id}/toggle-qr`, `GET /api/student/classes`, `GET /api/departments`
   - Attendances: `GET /api/classes/{id}/attendances`, `POST /api/attendances/scan`,
     `POST /api/attendances/face-checkin`, `PUT /api/attendances/{id}`,
     `POST /api/attendances/manual`, `GET /api/student/attendances`
   - Reports & GPS: `GET /api/admin/reports/student-stats`, `GET /api/reports/attendance/export`,
     `GET /api/campus-settings`, `PUT /api/admin/campus-settings`

4. Database (MySQL — ឈ្មោះ DB: `scan_in`)
   - `users`: `id`, `name`, `latin_name`, `email`, `password`, `role` (`admin`/`sub_admin`/`lecturer`/`student`),
